# Frontend

Next.js app listing short links and showing click analytics (`/analytics/{code}`).

| Script | Description |
| --- | --- |
| `npm run dev` | Dev server on http://localhost:3000 |
| `npm run build` | Production build (standalone output) |
| `npm test` | Unit tests (Vitest + Testing Library) |
| `npm run lint` | ESLint |

Env: `BACKEND_URL` (server-side only, default `http://localhost:8080`).
